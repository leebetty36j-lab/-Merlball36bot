# 🔄 Text Reverser Bot

A simple Telegram bot that reverses any text you send.

## 🚀 Features

- Reverse any text instantly
- Works with emojis and special characters
- No registration required
- 100% free

## 📱 Commands

| Command | Description |
|---------|-------------|
| `/start` | Welcome message |
| `/help` | Help menu |
| `/about` | About this bot |

## 🛠️ How to Use

1. Find the bot on Telegram
2. Send `/start` to begin
3. Send any text message
4. The bot will reply with reversed text

**Example:**
- You send: `Hello world`
- Bot replies: `dlrow olleH`
